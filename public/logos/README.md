# Logos institucionales

Coloca aquí los archivos de logo con estos nombres exactos:

- `espol-logo.png`  → Logo oficial de ESPOL
- `embs-logo.png`   → Logo de IEEE EMBS ESPOL

Los logos se mostrarán automáticamente en la parte inferior del sidebar.
Si los archivos no están presentes, el sidebar mostrará solo el texto institucional.

## Tamaño recomendado
- Fondo transparente (PNG)
- Altura: entre 20–40 px de alto en la interfaz
- No recortar ni deformar los logos originales
